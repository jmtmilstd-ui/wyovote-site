# Person and office additions (114 County Officeholders)

These CSVs extend the standard person-ID (`WY-LAST-FIRST`), offices-held, and candidacy tables for municipal, school-board, and judicial officers compiled for Weston County. Existing name-index IDs are reused. Minted IDs are flagged in `people_additions.csv`. This folder is on the 114 work branch only; it is not merged to main in this step.
